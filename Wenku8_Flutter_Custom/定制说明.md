# Wenku8_Flutter 定制版说明

本文件夹基于 `Nainlivz/Wenku8_Flutter` 公开源码快照（v0.5.2 快照）定制，针对两处使用痛点做了修改。

> **2026-11-24 更新：缺失模块已全部补齐。** 从 GitHub 上的衍生项目 `YLuzew/FanqieReader`（同为 Wenku8_Flutter 改版）中找齐了全部 19 个缺失模块并合并进来，另从 `P5UEDGK/Wenku8_Flutter` 交叉验证了本地导入相关模块。现在全项目 316 个 dart 文件、1247 个内部 import，**缺失数为 0**，源码完整性已达到可构建级别（本机未安装 Flutter SDK，未做实际编译验证）。

## 改动 1：漫画/图片页自适应屏幕并居中

**问题**：导入的漫画单页图片贴在屏幕顶部，下方留大片空白。

**根因**：`lib/pages.dart` 中单图整页判定特意排除了 `wenku-local:` 开头的本地图片，导致本地漫画走了"按尺寸贴图"路径（`Alignment.topCenter` 顶部对齐），而非"整页适配"路径。

**修改**：`lib/pages.dart` 第 8182 行附近，去掉对本地图片的排除条件，让本地单页漫画同样走 `fullPage: true`，由 `ReaderIllustrationFrame` 按当前屏幕做等比适配并垂直居中。

**效果**：漫画页按当前设备画面等比缩放、位置居中，不再顶在上方留白。

## 改动 2：听书内置男女声音色扩充

**问题**：听书音色只有（或经常只剩）一个女声。

**根因**：`lib/listening/models.dart` 原只内置 2 个兜底音色（晓晓女声、云希男声）；在线音色列表拉取失败时，`lib/listening/controller.dart` 的兜底路径会退回默认，`_LanguageVoicePicker` 里容易只剩一个可选。用户看到的"只有一个女声"通常是联网音色列表未成功加载导致的。

**修改**：
- `lib/listening/models.dart`：新增 `builtinChineseEdgeVoices`，内置 8 个合法 Edge 中文音色（晓晓/晓伊/晓北/晓妮女声，云希/云健/云扬男声）。
- `lib/listening/controller.dart`：`voicesForLanguage` 对 Edge 中文合并内置清单（在线结果优先、按 ID 去重），异常兜底返回完整内置清单而非两个音色。

**效果**：即使离线或在线列表加载失败，音色选择器也能显示多个男女声可选。联网正常时会额外合并内置音色，选项更丰富。

## 音色说明

这些音色基于微软 Edge 神经网络语音（edge-tts），生成语音需要联网；列表本身可离线显示。音色是否可用也取决于微软服务当前是否提供该 ID。

## 本地语音包方案（GitHub 开源资源）

GitHub 上有可用的**离线中文语音模型**，可作为系统 TTS 引擎供本 App 的"系统 TTS"音源调用，实现真正的本地离线朗读：

- **sherpa-onnx**（`k2-fsa/sherpa-onnx`）：提供 Android TTS 引擎 APK（可作为系统语音引擎被本 App 调用），以及大量中文离线模型。中文模型包括：
  - `vits-piper-zh_CN-huayan-medium`（华言普通话女声，64MB）
  - `vits-piper-zh_CN-xiao_ya-medium`（晓雅女声，58MB，int8 量化版仅 13MB）
  - `vits-piper-zh_CN-chaowen-medium`（超自然男声，58MB，int8 版 13MB）
  - `vits-zh-aishell3`（多说话人，含男女声，30MB）
  - `vits-melo-tts-zh_en`（中英双语，159MB）
- **Piper**（`OHF-Voice/piper1-gpl`，原 `rhasspy/piper`）：轻量本地神经 TTS，中文模型 60MB 左右，CPU 实时合成，GPL-3.0。
- 模型下载：sherpa-onnx 的 `tts-models` Release（646 个资源），piper 模型在 HuggingFace `rhasspy/piper-voices`。

**接入路径**：本 App 已支持"系统 TTS"音源（`lib/listening/system_tts_page.dart`）。安装 sherpa-onnx Android TTS 引擎 APK 并下载中文模型后，在 App 听书设置里切换到"系统 TTS"并选择对应引擎/音色，即可离线朗读。这是不改动 App 源码即可获得多音色离线语音的最实际方案。
