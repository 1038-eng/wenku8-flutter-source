## 四、Windows 桌面版

代码层面已兼容（sherpa_onnx 提供 Windows 插件），但本机缺少
**Visual Studio Build Tools 的「使用 C++ 的桌面开发」工作负载 + Windows SDK**，
所以还不能产出 exe。需要安装：

```
vs_buildtools.exe --quiet --wait --norestart \
  --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended
```

装好后：

```bash
flutter build windows --release
# 产物：build/windows/x64/runner/Release/ 整个目录可打包分发
```

### Windows 本地图书

Windows 端已接入与手机端**同一套书库和导入流程**（书库目录、缓存 key、
章节切分规则一致），入口在「本地」页：

- 点导入按钮 → 系统文件选择器（支持多选）；
- 或直接把文件从资源管理器**拖进「本地」页**完成添加。

支持格式比手机端更宽：TXT / EPUB / ZIP / HTML / XHTML / MD / FB2 / DOCX /
RTF / CSV / LOG / NFO / SRT 等；PDF / MOBI / AZW / AZW3 / PRC 会给出明确
的「Windows 版暂不支持」提示，不会静默损坏文件。文件选择器与转换器由
`lib/desktop_book_documents.dart` 提供，`desktop_drop` 负责拖拽。

安装器在这台机器上曾返回退出码 5002，根因是环境变量里同时存在
`HTTP_PROXY` 和 `http_proxy`（.NET 字典重复键）。只保留一种大小写后安装成功。
本次 Windows 版已验证 `flutter build windows --release` 成功（WIN_EXIT=0），
发布包为 `delivery/windows/wenku8_flutter_win64.zip`（158.1MB，
md5 `48f17c1084893d29c0cda5a80e57469d`）。解压后直接运行
`Release/wenku8_flutter.exe` 即可，不需要安装。Windows 工程已推 GitHub。

## 五、macOS / iOS 版（由你在 Mac 端完成）

这两端无法在 Windows 上交叉编译，需要 macOS + Xcode：

```bash
# macOS
flutter build macos --release
# iOS（需要 Apple Developer 签名配置）
flutter config --enable-macos-desktop   # 如未启用
flutter build ios --release
# 或 flutter build ipa --release --export-options-plist=<你的 ExportOptions.plist>
```

代码改动是跨平台的（`lib/` 与 `pubspec.yaml`），直接复用同一个
`Wenku8_Flutter_Custom/` 即可；需要注意：

- iOS 需要在 `ios/Runner/Info.plist` 检查ATS/文件访问权限描述；
- 模型资源约 206MB，iOS 包体较大，建议用按需下载或 App Store 分包策略评估；
- 首次使用解压到 Application Support 目录，逻辑已由 `path_provider` 处理；
- 粤语仍走 Edge 在线，离线只有普通话男女声。
