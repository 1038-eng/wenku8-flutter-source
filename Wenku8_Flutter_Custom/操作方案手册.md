## 三、新电脑环境搭建

### 3.1 版本要求（以源码为准）

从 `pubspec.yaml` 读到：

- 项目名 `wenku8_flutter`，版本 `0.5.2+2272`
- Dart SDK：`sdk: ^3.11.3` → 需要 **Dart ≥ 3.11.3** 的 Flutter 稳定版
- Gradle：项目自带 wrapper，**8.14**（首次构建自动下载）
- Android 原生库用 CMake + NDK 编译

### 3.2 安装步骤

1. **Flutter SDK**：https://docs.flutter.dev/get-started/install
   - 选 stable 通道；装完跑 `flutter --version`，确认 Dart 版本 ≥ 3.11.3。
   - 低版本会因 `sdk: ^3.11.3` 直接报 pubspec 解析失败。

2. **Android Studio**：安装 Android SDK + Android SDK Build-Tools + **NDK**（建议 25+）+ **CMake**。

3. **JDK 17**：https://adoptium.net ，装完 `java -version` 确认。

4. **验证**：
   ```bash
   flutter doctor -v
   ```
   至少保证 Flutter、Android toolchain、Java 三项打勾。

5. **首次拉依赖**（在定制版源码目录）：
   ```bash
   flutter pub get
   ```

> 提示：国内网络首次拉 pub 包和 Gradle 可能很慢，可配置 `PUB_HOSTED_URL` / `FLUTTER_STORAGE_BASE_URL` 镜像，Gradle 可换国内 distribution 镜像。

## 四、三条执行路线（按推荐顺序）

### 路线 A —— 零编译，先把听书用起来（当天就能做）

不需要新电脑、不需要编译：

1. 手机装官方阅读器 APK（v0.5.6）。
2. 再装 `sherpa-onnx-tts-engine-zh-chaowen-arm64.apk`（内置中文男声，离线可用）。
3. 系统设置 → 文字转语音输出 → 默认引擎选 sherpa-onnx。
4. 阅读器听书 → 音源切到"系统 TTS" → 选对应音色。
5. 效果：离线男声朗读，不用改任何代码。

> 漫画页面居中的改动只在定制版源码里，官方 APK 没有这个效果。要用到它必须走路线 B/C。

---

### 路线 B —— 先编译验证定制版源码（必做第一步）

**目的**：确认补齐后的源码真能编译，同时验证漫画居中 + 多音色的改动生效。这步不做，后面内置语音也没法做。

```bash
cd Wenku8_Flutter_Custom
flutter pub get
flutter build apk --release --split-per-abi
```

产物：`build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`

**签名说明（重要）**：

项目 `android/app/build.gradle.kts` 已有完整签名逻辑：
- 若 `android/key.properties` 不存在 → release 构建自动用 **debug 签名**，仍然可以安装，适合自测。
- 若存在 → 用你自己的 `distribution` 签名。

自测阶段**不用配 key.properties**，直接构建即可安装。安装前需先卸载官方版（签名不同，不能覆盖）。

**验证清单**：
- [ ] APK 能装、能启动
- [ ] 导入一张漫画图片 → 页面等比适配、垂直居中，不再贴顶留白
- [ ] 听书音色选择器能看到多个男女声（联网时更多，离线时至少 8 个内置）

若编译报错，多数出在合并进来的模块接口签名差异，见第六节排查。

---

### 路线 C —— 最终目标：内置离线语音的单一 APK

**目的**：一个 APK 装完即用，自带离线中文男/女声，不依赖外部引擎、不用联网。

详细技术方案见 `内置语音APK方案.md`，这里给执行顺序：

1. 路线 B 先编译通过（基线）。
2. `pubspec.yaml` 加 `sherpa_onnx` 依赖，模型文件加入 `assets`（建议 int8 量化版：男声 `vits-piper-zh_CN-chaowen-medium-int8` ≈ 13MB，女声 `vits-piper-zh_CN-xiao_ya-medium-int8` ≈ 13MB）。
3. `lib/listening/models.dart`：`ListeningSource` 增加 `local` 枚举，音色清单增加内置离线项。
4. `lib/listening/cache.dart` / `controller.dart`：`voicesForLanguage` / `_voiceInventory` 支持 `local` 分支，合成走 sherpa-onnx 本地引擎。
5. `lib/listening/widgets.dart`：音源/音色 UI 增加"内置离线"分组。
6. 模型随 APK 打包为 assets，首次启动解压到应用私有目录（避免直接 asset 读取的性能问题）。
7. 生成自己的签名密钥并配置 `android/key.properties`：

   ```bash
   keytool -genkey -v -keystore android/app/keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias wenku8
   ```
   `android/key.properties`：
   ```
   keyAlias=wenku8
   keyPassword=你的密码
   storeFile=app/keystore.jks
   storePassword=你的密码
   ```
   注意 `storeFile` 相对 `android/` 目录。

8. 构建：
   ```bash
   flutter build apk --release --target-platform=android-arm64
   ```
9. 卸载官方版后安装自测；确认离线（关WiFi/流量）听书仍能出声。

**已知代价**：体积约 +26MB；新签名不覆盖官方版，书架/阅读记录不通用；模型许可证（Apache-2.0 / MIT / CC-BY）需在"关于/许可"页保留声明。

## 六、常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| `pubspec.yaml` 报 SDK 版本不符 | Flutter 太旧，Dart < 3.11.3，换 stable 新版 |
| Gradle 下载失败 | 网络问题，换 Gradle 镜像或修改 `gradle-wrapper.properties` 的 distributionUrl |
| NDK / CMake 报错 | Android Studio 里补装 NDK 25+ 和 CMake |
| 某个 dart 文件找不到模块 | 已补齐 19 个模块；若仍缺，从 `YLuzew/FanqieReader` 同名路径拷贝 |
| 合并模块接口签名不一致 | 对照 `定制说明.md` 的补齐记录，按主项目 API 微调签名 |
| 安装提示"应用未安装" | 签名冲突，先卸载官方版；或架构不匹配（确认用 arm64 包） |
| 听书还是只有一个音色 | 检查 `lib/listening/controller.dart` 的 `voicesForLanguage` 是否含 `builtinChineseEdgeVoices` 合并逻辑 |
